# App Paril — Privacy Checklist

- [ ] Explain what is stored locally and what is sent to the backend.
- [ ] Do not automatically scan messaging apps.
- [ ] Import only user-selected exports.
- [ ] Confirm permission/consent to process messages from all relevant participants.
- [ ] Allow sender exclusions before indexing.
- [ ] Allow deletion of original imported data, derived style profile, embeddings and backend copies.
- [ ] Keep private photos/audio local unless explicit sync is implemented.
- [ ] Never commit real chat exports, private photos, voice clips, `.env`, API keys or database credentials.
- [ ] Do not log raw messages or full prompts.
- [ ] Label AI-generated text clearly.
- [ ] Gate private content in Paril mode; Friends/Family mode must not expose it by default.
- [ ] Document the limitations of Android alarm playback.
