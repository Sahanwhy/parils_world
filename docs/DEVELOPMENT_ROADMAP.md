# Development Roadmap

1. Foundation: theme, routing, welcome/role selection, developer message, dashboard.
2. Local-first content: relationship timer, photo gallery, memories, settings/privacy.
3. Game: Flame Flappy Bird, scoring, restart, local high score.
4. Voice alarm: local recordings, scheduling, permissions, native Android support and device testing.
5. Backend foundation: FastAPI, config, health endpoint, MongoDB connectivity and tests.
6. ParilGPT RAG: explicit import, preview, sender mapping, parsing, style profile, embeddings, vector store, Mistral generation, deletion.
7. Hardening: tests, privacy review, responsive polish, APK release build, setup guide.
